# 概率统计 · 从零推导

把《概率统计》课件第一至三章（唐军民主讲，共 301 页、20 节）改写成一份从初中数学起步、逐层推到专家水平的单文件交互式学习页面。

产物：`概率统计从零推导.html`（约 842 KB，27 个章节）。

## 怎么用

双击打开，或者拖进浏览器。没有服务器、没有外网依赖，KaTeX 的样式、脚本、字体全部内联在文件里，断网也能正常显示公式。

- 左侧（桌面）或顶栏"目录"按钮（手机）打开章节目录，点章节名跳转。
- 每章顶部有面包屑，底部有"上一章 / 下一章"按钮，手机上顶栏右侧还有前后箭头，滚动时一直可见。
- 每章内的推导过程默认折叠，点标题展开。折叠可嵌套，逐层点。
- 公式块如果太长会内部横向滚动，不会把整页撑宽。

## 记号约定

全程沿用课件的写法，不用教材里常见的 X、Y：

- 随机变量写成 ξ、η
- 概率写成 P
- 分布函数写成 F(x)
- 密度写成 p(x)
- 分布列写成 p_k

第 0 章有一张记号对照表，第一次出现的地方也都另给了白话解释。

## 重新构建

HTML 是脚本拼出来的，不要直接改 HTML——改章节源文件再重跑。

```bash
python3 insert_chapters.py
```

脚本会把 `build_skeleton.py` 生成的骨架与 `chapters_a.py` 到 `chapters_e.py` 五批章节正文合并，输出 `概率统计从零推导.html`。幂等：重复跑结果一致；如果骨架里找不到占位锚点，会自动重跑一遍骨架。

章节源文件按写作批次拆分，每条都是纯 Python 字符串，改文字只动对应文件：

| 文件 | 内容 |
|---|---|
| `build_skeleton.py` | 骨架：CSS、JS、KaTeX 内联、27 章目录 |
| `chapters_a.py` | 第 0–4 章（概览与四块地基） |
| `chapters_b.py` | 第 5–11 章（第一章 7 节） |
| `chapters_c.py` | 第 12–18 章（第二章 7 节） |
| `chapters_d.py` | 第 19–24 章（第三章前 6 节） |
| `chapters_e.py` | 第 25–26 章（3.6、3.7 与总复习） |

`katex.min.css`、`katex.min.js`、`auto-render.min.js`、`fonts/` 是构建依赖，改名或删除会导致构建失败。

## 已知边界

1. 只覆盖第一至三章。第四章（大数定律、中心极限定理、数理统计）不在范围内，第 26 章末尾给了衔接说明。
2. 课件的公式层是图片，文本层提取后下标、积分号、矩阵括号全被打散，只能用来抓章节结构和定理编号。具体公式与例题是渲染页面读图核对的，关键页留在 `shots/`。
3. 课件里没有大量例题，部分数值例子（摸球、投篮、体检、三角形区域、两个均匀分布相加等）是自拟的，每个都手算验证过，正文里注明是假设数据。
4. 部分较长的推导（正态特征函数的积分、特征函数唯一性定理）只给结论和用法，没有展开证明，正文里写明"这里不证"。要补的话在三处：第 25.3 节。
5. 手机端顶栏固定，正文为其留了 52px 顶部内边距；若在极窄屏（<320px）上阅读，公式块可能仍需横向滚动。
